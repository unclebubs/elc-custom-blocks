Custom WordPress blocks for the ELC website including podcast listings, journal club content, navigation, and more.

== Description ==

ELC Custom Blocks is a comprehensive WordPress plugin that provides custom Gutenberg blocks specifically designed for the ELC website. This plugin includes blocks for:

* Account login functionality
* Bootstrap pagination
* Papers tab navigation
* Journal club content and headers
* Podcast listings and categories
* Year-based navigation
* Summit registration buttons
* Search functionality

All blocks are built with modern WordPress standards and are fully compatible with the Gutenberg editor.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/elc-blocks` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. The blocks will automatically be available in the Gutenberg editor under the "ELC Blocks" category.

== Frequently Asked Questions ==

= Are these blocks compatible with any theme? =

Yes, these blocks are designed to work with any properly coded WordPress theme. However, some styling may be optimized for the ELC theme.

= Can I customize the block styles? =

Yes, the blocks include CSS classes that can be customized through your theme's style.css file or through the WordPress Customizer.

= Do the blocks require any external dependencies? =

The blocks are self-contained and include all necessary assets. Some blocks may use Bootstrap classes for styling.

== Block List ==

This plugin includes the following blocks:

* **Account Login** - User authentication block
* **Bootstrap Pagination** - Styled pagination component
* **ELC Papers Tab Navigation** - Navigation for academic papers
* **Journal Club Header** - Header component for journal club pages
* **Journal Club Listings** - Display journal club entries
* **Journal Year Navigation** - Year-based navigation for journals
* **Latest Journal Club Content** - Show recent journal club content
* **Most Recent Podcast** - Display the latest podcast
* **Most Viewed Podcast** - Show popular podcast content
* **Podcast Category Cards** - Grid of podcast categories
* **Podcast Category Info** - Information about podcast categories
* **Podcast Listing** - List of podcast episodes
* **Podcast Search Form** - Search functionality for podcasts
* **Podcast Year Navigation** - Year-based podcast navigation
* **Summit Register Interest Buttons** - Registration CTAs for events
